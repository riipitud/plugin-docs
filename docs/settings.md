# Settings

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `Intensity` | float | `1.0` | Overall strength of the effect. |
| `bEnabled` | bool | `true` | Toggles the effect at runtime. |
| `Radius` | float | `500.0` | Effect radius in Unreal units. |

??? note "Advanced"
    Collapsible sections are good for rarely used options.
